# Data-Cleaning-and-Transformation-Using-Microsoft-Excel
Simple overview of use/purpose

This project demonstrates the process of cleaning, transforming, and preparing raw datasets for analysis using Microsoft Excel. It focuses on improving data quality by handling missing values, correcting inconsistencies, removing duplicate records, and applying formatting and transformation techniques.

Description

Real-world datasets often contain missing values, duplicate records, inconsistent formatting, and unstructured text fields that can negatively impact data analysis. The objective of this project is to apply Microsoft Excel's data cleaning and transformation capabilities to convert raw data into a structured, standardized, and analysis-ready format.

The project covers essential data preprocessing activities such as identifying and handling missing values, removing duplicate records, standardizing text formats, restructuring columns, applying conditional formatting, and formatting dates and currency values. These techniques help improve data quality, usability, and readability, enabling more accurate reporting and decision-making.

Getting Started
Dependencies

The following software is required to run this project:

Microsoft Excel 2016 or later
Windows 10/11, macOS, or any operating system supporting Microsoft Excel

Executing Program
How to run the project
Open the Excel workbook.

Review the raw dataset provided in the source sheet.
Perform the following data cleaning activities:

Handle missing values
Remove duplicate records
Standardize text fields
Format dates and currency columns
Apply conditional formatting rules
Transform and restructure columns
Save the cleaned dataset.
Use the prepared dataset for analysis and reporting.
Help
Common Issues
Dates not displaying correctly
Ensure the column format is set to Date.
Use the custom format:
DD-MM-YYYY
Currency values appearing as text
Remove special characters if necessary.
Convert the column to Currency format.
Duplicate records not removed
Select the entire dataset before using the "Remove Duplicates" feature.
Verify that all relevant columns are selected.
